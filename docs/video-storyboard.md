# 视频分镜脚本说明

> 本文档用自然语言逐幕讲解数据变化视频的每一个场景：内容、元素、动效、数据来源，
> 以及对应的代码位置，方便你直接修改 `bmon/video.py` 调整视频。
> 修改后运行 `python main.py video` 即可重新渲染查看效果。

## 一、脚本位置与调用方式

| 内容 | 位置 |
|---|---|
| 视频生成主模块（全部场景代码） | `bmon/video.py` |
| 命令行入口（`video` 子命令） | `main.py` 中的 `cmd_video`（约第 240 行） |
| 输出视频 | `output/videos/report_<起>-<止>.mp4` |
| 数据来源 | `data/monitor.db` 的 `snapshots` / `videos` / `accounts` 表 |

```bash
python main.py video                       # 默认全部快照历史
python main.py video --days 7              # 仅最近 7 天
python main.py video --from 2026-08-16 --to 2026-08-21
```

技术流程：`collect()` 汇总数据 → matplotlib 逐帧渲染（30fps）→
imageio-ffmpeg 自带编码器输出 1920×1080 H.264 MP4。

## 二、全局设定（video.py 第 23~38 行）

- **分辨率/帧率**：1920×1080 @ 30fps（`make_video` 内 dpi=150、figsize 换算；fps 为参数）
- **场景与时长**：`SCENES` 列表（第 37 行）——直接改秒数即可调整每幕时长，
  增删场景需同时在 `_DRAW` 映射表（第 685 行）注册绘制函数
- **配色**（第 26~34 行）：
  - `BG` 背景深色、`PANEL` 面板、`BORDER` 边框、`GRID` 网格
  - `TEXT` 主文字、`DIM` 次要文字、`CYAN` 强调青、`GREEN` 增量绿、`GOLD` 前三名琥珀金
  - 三个游戏的颜色沿用图表体系（原神蓝 #00A1D6 / 星铁粉 #F25D8E / 绝区零紫 #7B5FFF）
- **通用动效工具**：`_ease`（缓出曲线，所有数字滚动/生长的节奏）、
  `_fade`（每幕开头 15 帧淡入、结尾 10 帧淡出）

## 三、分镜逐幕讲解

### 第 1 幕 · 片头（0.0s ~ 3.0s）｜函数 `_sc_title`（第 222 行）

- **画面**：居中排版。主标题"B站官号数据变化报告"（50pt 加粗白字），
  下方青色横线从中心向两侧展开（缓出动画），再依次淡入监测时段
  （如 2026-08-16 ~ 2026-08-21，青色）与副题"播放量 · 快照数据 · 本地监测"（灰色小字），
  底部为 "bmon · bilibili-monitor" 落款
- **动效**：横线展开 + 文字分层淡入
- **想改什么**：标题文案直接改 `ax.text` 的字符串；展开速度改 `_ease(i / (n-1))` 的分母

### 第 2 幕 · 总览（3.0s ~ 9.5s）｜函数 `_sc_overview`（第 237 行）

- **画面**：
  - 页头："总览" + 副题"全账号合计与分游戏明细"，右上角时段
  - **上排三张合计卡片**：监测视频数 / 累计播放 / 本期播放增量（绿色加号）
  - **下方三行分游戏面板**：原神、崩坏星穹铁道、绝区零各一行，
    每行 = 色点 + 游戏名 + 视频数 + 累计播放 + 本期增量
  - **底部时间轴**：整周日期刻度，青色进度线 + 圆点 + 当前日期标签，
    与数字滚动进度同步向右推进
- **动效**：所有数字从 0 滚动到目标值（缓出曲线，约占本幕前 80% 时长），时间轴同步推进
- **数据**：合计 = 全库统计；分游戏 = 按账号聚合（`collect()` 第 118~132 行）
- **想改什么**：卡片/行的位置改 `x`、`y` 浮点坐标（0~1 画面比例）；
  增删指标列改 `cards` 与 `cols` 列表

### 第 3 幕 · 播放量走势（9.5s ~ 19.5s）｜函数 `_sc_trend`（第 339 行）

- **画面**：深色圆角面板内的折线图。横轴=日期（每日刻度 MM-DD），
  纵轴=播放量（自动收缩到数据实际范围，不从 0 起，差异更清晰）；
  **监测期内变化最显著的 Top8 视频**各一条彩色折线，快照点带圆形标记；
  右侧 8 个标签（色点 + 标题两行完整折行 + 数值）
- **动效**：
  - 竖向虚线扫描线推进，折线在快照点间**线性插值、平滑生长**
  - **右侧标签纵向位置跟随各自折线端点**，与左边折线一一对应，
    自动防重叠、帧间平滑过渡（`_side_timeline`，第 309 行）
  - 右侧数值随插值**连续跳字**（不是快照点才变）
  - 扫描完成后**定格 3 秒**再切下一幕
- **数据**：`collect()` 选"期内有增长的视频按期末播放取 Top8"（第 111~113 行）；
  平滑采样用 `_interp_value`（第 67 行）每条线采 121 个点
- **想改什么**：条数改 `[:8]`；线宽/标记改 `lw=2.8`、`ms=5`；
  扫描时长/定格改 `i / max(1, n - 90)`；标签防重叠间距/跟随速度改
  `_side_timeline` 里的 `gap=0.075`、`0.3`

### 第 4 幕 · 净增量走势 · 视频（19.5s ~ 28.5s）｜函数 `_sc_gains_videos`（第 415 行）

- **画面**：与上一幕同版式的折线图，纵轴=**净增量**（从 0 起）。
  Top8 视频各自的净增量曲线（账号色 + 圆形标记），
  右侧标签同样**跟随折线端点**、数值连续跳字（绿色）
- **动效**：扫描线推进、曲线插值平滑生长、标签跟随；结尾定格 3 秒
- **数据**：每个视频的增量 = 当前播放 − 期初基线
- **想改什么**：曲线粗细节 `lw=2.6`

### 第 5 幕 · 净增量走势 · 分游戏（28.5s ~ 36.5s）｜函数 `_sc_gains_games`（第 484 行）

- **画面**：三条粗线（lw=3.4）= 三个游戏全部监测视频的**合计净增量**曲线，
  曲线为 121 点插值采样的**平滑曲线**（不加密集标记点，仅线端一个圆点），
  右侧三张卡片按合计增量排序：色点 + 游戏名 + 绿色增量数字（滚动）
- **动效**：同扫描平滑生长；卡片数字同步滚动；结尾定格 3 秒
- **数据**：对账号全部有效视频的快照序列插值后逐时刻求和
  （`collect()` 第 135~151 行，采样 121 个时间点）
- **想改什么**：粗线宽度 `lw=3.4`；卡片数量 `[:3]`

### 第 6 幕 · 播放量竞跑（36.5s ~ 46.5s）｜函数 `_sc_bars`（第 586 行）

- **画面**：条形竞跑（Bar Race）。10 条横向彩色条 = 本期增量 Top10 视频：
  - **条形长度 = 当前播放量**，横轴=播放量：最高者占满、其余等比缩放；
    顶部有横轴刻度与竖向网格；横轴范围逻辑在 `_bar_axis`（第 571 行）：
    若各视频播放量相对差异不足最高值的 45%，自动抬升轴起点（截断轴，"//"标记+提示）
  - 条形左侧：视频标题（小号、去游戏前缀、两行完整折行不截断，`_wrap2` 第 73 行）；条尾标注"+当日新增"（增量为 0 时隐藏，前三名琥珀金）
  - 画面最右一列："当前播放量"精确数值
  - **底部日期横轴**：整周日期刻度，青色进度线 + 圆点 + 日期标签标示当前演到哪一天
  - 左下角游戏图例
- **动效**：日期从左到右扫描约 6.6 秒——条形随每日数据变长、
  **排名实时重排**（条形上下平滑换位）、数字同步滚动；开头定格 0.4 秒、**结尾定格 3 秒**
- **数据**：快照序列线性插值到任意时刻（`_interp_value`，第 67 行）；
  排名平滑过渡在 `_race_timeline`（第 545 行）预计算（`hold=12, hold_end=90`）
- **想改什么**：条数改 `collect()` 里 `[:10]`；条形区域改 `left/right/top_y/bot_y`；
  截断轴触发阈值改 `_bar_axis` 里的 `0.45`；换位平滑速度改 `_race_timeline` 中的 `0.28`

### 第 7 幕 · 片尾（46.5s ~ 49.5s）｜函数 `_sc_end`（第 672 行）

- **画面**：居中"本期报告 · 完"，青色短线展开，下方监测时段与
  "生成于 YYYY-MM-DD HH:MM · 数据来自本地快照"
- **动效**：短线展开 + 淡入

## 四、常见修改速查

| 想改的东西 | 改哪里 |
|---|---|
| 每幕时长 / 增删幕 | `SCENES`（第 37 行）+ `_DRAW` 映射表 |
| 配色 | 第 26~34 行常量 |
| 标题、副题、文案 | 各 `_sc_*` 函数里的 `ax.text(...)` 字符串 |
| Top 条数（8/10） | `collect()` 里的 `[:8]`、`[:10]` |
| 标题折行宽度 | `_wrap2(标题, 显示宽度)`：趋势槽位 24、竞跑 30（中文计 2，自动放宽不丢字） |
| 动画快慢 / 结尾定格 | `_ease` 的分母、各幕 `n - 90`（90 帧=3 秒定格）、竞跑 `hold/hold_end` |
| 字体大小 | 各 `fontsize=` 参数 |
| 布局位置 | 各坐标浮点数（0~1 画面比例，左下为原点） |
| 输出文件名/路径 | `make_video` 末尾 `out_path` 逻辑 |

## 五、注意事项

- 画面坐标是 0~1 的比例制（左下原点），改布局时成组微调即可
- 所有场景共用 `_header` 页头与 `_panel` 圆角面板，改这两个函数全局生效
- 每幕开头 15 帧 / 结尾 10 帧是淡入淡出区，重要内容避免放在这两段
- 渲染一次约 2 分钟（1485 帧），改完建议先用 `--days` 缩短时段快速试效果
